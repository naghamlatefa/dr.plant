Dr.Plant - تطبيق لتشخيص الأمراض النباتية
هو تطبيق مبتكر باستخدام flutter و الذكاء الاصطناعي لتشخيص الأمراض النباتية استنادًا إلى صورة للورقة النباتية. يقوم التطبيق بتحليل الصورة باستخدام تقنيات الذكاء الاصطناعي لتحديد نوع المرض الذي يعاني منه النبات، ومن ثم يقدم إرشادات للتعامل مع المرض باستخدام المنطق الضبابي (Fuzzy Logic).
